# Project 01: NYC Rat Complaints

## Executive Summary

This project analyzes NYC rat complaint data to better understand where and when rat reports are most common across the city. The main motivation was to turn a large complaint dataset into readable visual summaries and an interactive map that make the pattern of rat reports easier to explore.

The project focuses on complaint location, borough-level patterns, time-based trends, and complaint status. The strongest part of the project is the interactive map because it lets the reader move around the city and inspect where complaints are concentrated instead of only viewing summary counts.

## Data Used

This project uses NYC rat complaint data. The dataset includes complaint dates, boroughs, status information, location descriptions, and latitude/longitude coordinates.

## Requirements Addressed

### 1. Interactive Chart

This project includes an interactive NYC rat complaint map.

The interactive map lets the reader zoom, pan, and explore complaint locations across the city. This is useful because rat complaint patterns are spatial, and the map makes the clusters easier to understand than a static chart alone.

### 2. Accessibility

Accessibility was addressed by using colorblind-friendly colors, readable labels, and alt text for the main figures. The map and charts avoid unnecessary color clutter and use stronger contrast where possible.

### 3. Before and After Redesign

The redesign section improves one of the original charts by reducing clutter, improving labels, and using a more accessible color palette. The goal of the redesign was to make the main complaint pattern easier to read without changing the actual data.

## Main Findings

Rat complaints are not evenly distributed across NYC. Some boroughs and neighborhoods show much higher complaint activity than others.

The time-based charts also show that complaint volume changes across the year instead of staying completely flat. The spatial map adds more context by showing where those complaints are concentrated.

## Future Directions

Future work could compare rat complaints with sanitation data, restaurant density, building age, or population density. Adding those variables would help explain why some areas have more complaints instead of only showing where complaints occur.
